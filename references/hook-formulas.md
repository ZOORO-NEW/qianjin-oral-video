# 开场Hook公式库

## 一、6大Hook类型

### 1. 反常识型

**公式**：`你知道吗？[反常识事实]`

**变体**：
- `[常识观点]？大错特错。`
- `所有人都以为[常识]，但真相是——`
- `你以为的[常识]，其实[真相]`

**示例**：
- "你知道吗？90%的人涨粉方式是错的"
- "勤能补拙？大错特错。方向不对，越勤越拙。"
- "所有人都以为内容越多越好，但真相是——少才是多"

**适用场景**：认知颠覆类、方法论类、行业真相类

---

### 2. 数据冲击型

**公式**：`一个数字吓你一跳：[震撼数据]`

**变体**：
- `[数据]%的人不知道——`
- `只有[数据]%的人能做到——`
- `我调研了[数据]个案例发现——`

**示例**：
- "一个数字吓你一跳：1条视频赚了17万"
- "83%的自媒体账号活不过6个月——"
- "只有7%的人能做到这一步——"

**适用场景**：行业数据类、对比分析类、调研报告类

---

### 3. 身份认同型

**公式**：`做[身份]的，这条视频你一定要看完`

**变体**：
- `如果你是[身份]，这条能帮你——`
- `[身份]的朋友们注意了——`
- `做了[数字]年[身份]才悟出来的——`

**示例**：
- "做自媒体的，这条视频你一定要看完"
- "如果你是创业者，这条能帮你省10万"
- "做了8年运营才悟出来的3个真相"

**适用场景**：职场干货类、行业经验类、技能教程类

---

### 4. 悬念型

**公式**：`我后悔知道得太晚了——[悬念]`

**变体**：
- `这件事要是早知道就好了——`
- `我花了[X]年才搞明白——`
- `最后我才发现——`

**示例**：
- "我后悔知道得太晚了——涨粉的秘密居然这么简单"
- "这件事要是早知道就好了——原来XX才是关键"
- "我花了3年才搞明白——XX的核心不是XX，是YY"

**适用场景**：经验分享类、个人故事类、方法论揭秘类

---

### 5. 对比冲突型

**公式**：`同样做XX，有人X有人Y`

**变体**：
- `[群体A]月入X万，[群体B]颗粒无收——区别就一点`
- `[正面案例] vs [反面案例]——差距在哪？`
- `同样是XX，为什么有人赚有人亏？`

**示例**：
- "同样做自媒体，有人月入3万有人颗粒无收"
- "张三月入5万，李四一分不赚——区别就一点"
- "同样是开店，为什么有人赚有人亏？"

**适用场景**：对比分析类、差距揭秘类、方法论对比类

---

### 6. 痛点直击型

**公式**：`是不是每次[场景]都[痛点]？`

**变体**：
- `[痛点]的痛我懂——`
- `你是不是也[痛点]？`
- `终于有人把[痛点]说清楚了——`

**示例**：
- "是不是每次写文案都写不出来？"
- "涨粉涨不上去的痛我懂——"
- "你是不是也觉得做自媒体越来越难？"
- "终于有人把AI焦虑说清楚了——"

**适用场景**：痛点共鸣类、解决方案类、行业困境类

---

## 二、Hook组合技巧

### 组合1：数据+反常识（最强组合）

```
"83%的自媒体账号活不过6个月——但活下来的那个17%，做了一件所有人忽略的事"
```
**为什么强**：数据建立权威感 → 反常识制造悬念 → 两个Hook叠加效果

### 组合2：身份+痛点

```
"做自媒体的，是不是每次写文案都写不出来？今天给你3个方法"
```
**为什么强**：身份筛选目标受众 → 痛点建立共情 → 解决方案给期待

### 组合3：对比+悬念

```
"同样做自媒体，有人月入3万有人颗粒无收——差距不在勤奋，在你知道的这个秘密"
```
**为什么强**：对比制造好奇 → 悬念引出核心 → 观众不想错过答案

## 三、Hook禁忌

| 禁忌 | 说明 | 反面示例 |
|------|------|----------|
| 铺垫型 | 前3秒浪费在寒暄上 | "大家好，今天我们来聊一个话题" |
| 概念型 | 太抽象不具体 | "今天聊聊自媒体运营的核心逻辑" |
| 问题型 | 提问但答案不新鲜 | "你知道自媒体怎么做吗？" |
| 标题型 | 只是念标题 | "AI不会取代你，但会用AI的人会" |
| 平淡型 | 无情绪无冲突 | "今天分享一个关于XX的想法" |

## 四、不同平台Hook适配

| 平台 | Hook偏好 | 原因 |
|------|---------|------|
| 抖音 | 反常识+数据冲击 | 需要极速刺激，3秒内必须制造冲突 |
| 视频号 | 痛点共鸣+生活场景 | 受众30-50岁，更看重"跟我有关" |
| B站 | 悬念+故事 | 有耐心听完开头，但需要好奇心驱动 |
| 小红书 | 身份认同+痛点 | "姐妹们"标签+痛点直击最有效 |
