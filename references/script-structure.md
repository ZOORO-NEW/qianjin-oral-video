# 口播脚本结构模板

## 一、脚本骨架

### 短视频版（抖音/视频号/小红书，60-90秒）

```
[0-3秒]   开场Hook —— 留住观众
[3-15秒]  Hook验证 —— 用1个数据/案例验证Hook
[15-40秒] 主体核心 —— 2-3个论点紧凑推进
[40-70秒] 方法/行动 —— 给可操作建议
[70-90秒] 金句收尾+CTA —— 金句+互动引导
```

### 中视频版（B站知识区，5-10分钟）

```
[0-30秒]  故事开场 —— 具体场景/案例/悬念
[30秒-3分] 论点1+信息高潮点 —— 弹幕触发
[3-6分]   论点2+信息高潮点 —— 弹幕互动引导
[6-9分]   论点3+反转/冷知识 —— 深度展开
[9-10分]  金句收尾+预告+三连引导
```

## 二、开场Hook模板

### Hook类型与示例

| 类型 | 公式 | 示例 |
|------|------|------|
| 反常识型 | "你知道吗？[反常识事实]" | "你知道吗？90%的人涨粉方式是错的" |
| 数据冲击型 | "一个数字吓你一跳：[数据]" | "一个数字吓你一跳：1条视频赚了17万" |
| 身份认同型 | "做[身份]的，这条看完" | "做自媒体的，这条视频你一定要看完" |
| 悬念型 | "我后悔知道得太晚了——[悬念]" | "我后悔知道得太晚了——涨粉的秘密居然这么简单" |
| 对比型 | "同样做XX，有人X有人Y" | "同样做自媒体，有人月入3万有人颗粒无收" |
| 痛点直击型 | "是不是每次[场景]都[痛点]？" | "是不是每次写文案都写不出来？" |

详见 `hook-formulas.md`（含变体和组合技巧）

## 三、段落模板

### 主体段落标准格式

每个主体段落按以下结构组织：

```
[XX-XX秒] 段落标题

🎬 视觉指令：
  - 镜头：[近景/中景/远景/特写]
  - B-roll：[描述补充画面素材]
  - 道具/背景：[需要的道具或背景变化]
  - 字幕弹出：[关键信息字幕]

🗣 口播台词：
  [口语化的台词文本]

📝 字幕要点：
  [核心信息点，≤15字，观众不听也能看懂]

💡 情绪标记：
  [语气/节奏/表情指引]
```

### 段落衔接句式库

从一段过渡到下一段，不能干巴巴地说"接下来"，要用有节奏感的衔接：

**加速型**（制造紧迫感）：
- "还有一个更狠的"
- "这事还没完"
- "但最离谱的是什么？"
- "你以为这就完了？"

**反转型**（制造认知冲击）：
- "但真相是——"
- "你可能想不到——"
- "关键不在XX，在YY"
- "很多人以为是A，其实是B"

**深挖型**（制造好奇心）：
- "为什么这么说？"
- "原因很简单，但大多数人没意识到——"
- "背后有个逻辑——"

## 四、结尾模板

### 金句+CTA标准结构

```
[XX-XX秒] 金句收尾+CTA

🎬 视觉指令：
  - 镜头：近景，表情坚定
  - 字幕弹出：金句文字

🗣 口播台词：
  [金句] + [CTA话]

📝 字幕要点：
  [金句文字，≤25字]

💡 情绪标记：
  坚定 → 语气下沉，节奏放慢
```

### CTA话术库

| 平台 | CTA类型 | 示例 |
|------|--------|------|
| 抖音 | 点赞+关注 | "觉得有用的点赞收藏，关注我，后面还有更狠的" |
| 视频号 | 转发+点赞 | "觉得有道理的转发给朋友，别让身边的人走弯路" |
| B站 | 三连 | "觉得有帮助的来个三连，下期讲XX，记得关注" |
| 小红书 | 收藏 | "姐妹们记得收藏！下次写文案直接翻出来用" |

## 六、完整脚本示例

### 抖音口播脚本示例（选题：AI不会取代你）

```
━━━ 口播视频脚本 ━━━

【标题】
  1. 99%的人都搞错了！AI不会取代你，但这件事会
  2. AI焦虑？3个真相让你瞬间清醒
  3. 别怕AI取代你——怕的是你不会用它

【封面文案】
  主标题：AI不会取代你
  副标题：但会用AI的人会

【预估时长】75秒

━━━ 脚本正文 ━━━

[0-3秒] 开场Hook

🎬 视觉指令：
  镜头：近景，直视镜头
  字幕弹出：AI不会取代你
  音效：鼓点

🗣 口播台词：
  你知道吗？90%的人对AI的担心，方向全搞错了。

📝 字幕要点：90%担心方向错了

💡 情绪标记：严肃开场，制造悬念

---

[3-15秒] Hook验证

🎬 视觉指令：
  镜头：中景
  B-roll：数据图表画面
  字幕弹出：AI取代率：34%

🗣 口播台词：
  一个数字吓你一跳——有报告说AI会取代34%的岗位。但真正被取代的，不是不会AI的人，是不愿意学的人。

📝 字幕要点：被取代的是不愿意学的人

💡 情绪标记：数据冲击→判断转折

---

[15-40秒] 主体核心

🎬 视觉指令：
  镜头：近景切换
  字幕弹出：3个真相

🗣 口播台词：
  三件事你必须知道。第一，AI是放大器，不是替代品。会用AI的人效率翻倍，不会的人原地踏步。第二，AI不是你的竞争对手，是你的新工具。就像计算器没取代数学家，只是让他们算得更快。第三，最危险的不是AI太强，是你太弱。**AI搞定80%，那20%的人味儿才是差距。**

📝 字幕要点：AI是放大器/AI是工具/20%人味是差距

💡 情绪标记：递进式——每点节奏加速，金句处放慢加重

---

[40-70秒] 方法行动

🎬 视觉指令：
  镜头：中景
  B-roll：手机操作画面
  字幕弹出：3步上手

🗣 口播台词：
  怎么做？三步。第一步，今天就开始用AI写一段文案。第二步，把AI出的东西改出你自己的味道。第三步，连续用7天，你会发现效率变了，思路也变了。

📝 字幕要点：今天用/改味道/用7天

💡 情绪标记：实操节奏，平稳推进

---

[70-75秒] 金句收尾+CTA

🎬 视觉指令：
  镜头：近景，表情坚定
  字幕弹出：AI不会取代你，会用AI的人会
  音效：安静→收束

🗣 口播台词：
  **AI不会取代你，会用AI的人会。**觉得有用的点赞收藏，关注我，后面还有更狠的。

📝 字幕要点：AI不会取代你，会用AI的人会

💡 情绪标记：金句放慢加重→CTA自然收束

━━━ 配套素材 ━━━

【标题文案】
  1. 99%的人都搞错了！AI不会取代你，但这件事会
  2. AI焦虑？3个真相让你瞬间清醒
  3. 别怕AI取代你——怕的是你不会用它

【封面文字】
  主标题：AI不会取代你
  副标题：但会用AI的人会

【话题标签】#AI焦虑 #自媒体干货 #AI工具 #搞钱

【评论区引导】你现在用AI了吗？用的哪个工具？评论区聊聊👇
```
