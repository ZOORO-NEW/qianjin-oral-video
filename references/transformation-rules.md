# 长文→口播转化规则

## 一、句式转换规则

口播脚本不是"读稿"，是"说话"。从长文到口播，核心是**口语化+节奏化+视觉化**。

### 句式转换对照

| 长文句式 | 口播句式 | 转换规则 |
|---------|---------|---------|
| "值得注意的是，这一趋势值得关注" | 删掉，直接说核心 | 删空话，只留干货 |
| "综上所述，我们可以得出结论" | "说白了就一句话——[结论]" | 说白了/核心是替换总结 |
| "基于纵向实证研究的多维度分析" | "我调研了100个案例发现——" | 学术腔→口语+具体数字 |
| "众所周知，互联网的发展日新月异" | 删掉或改为具体事实 | 删掉"众所周知"类套话 |
| "这个问题见仁见智，各有道理" | "关键不在XX，在YY" | 骑墙→有立场 |
| "企业应该以用户为中心" | "别想着赚快钱——想清楚用户需要什么再说" | 空话→具体建议 |
| 长句（30+字） | 拆成2-3个短句 | 1个长句→2-3句≤18字 |
| 书面连接词"然而""因此" | "但""所以""说白了" | 书面→口语连接词 |

## 二、结构重组规则

### 长文结构 → 短视频口播结构（60-90秒）

**长文原始结构**：
```
痛点引入 → 论点1 → 论据1 → 论点2 → 论据2 → 论点3 → 论据3 → 金句收尾
```

**重组为口播**：
```
[0-3秒]   Hook：选最反常识/最震撼的观点做开头
[3-15秒]  Hook验证：用1个数据/案例证明
[15-40秒] 核心推进：2-3个论点紧凑输出（删掉冗长论据，只留精华）
[40-70秒] 方法行动：从结论推导出可操作建议
[70-90秒] 金句+CTA：提炼1个传播金句 + 互动引导
```

### 长文结构 → B站中视频口播结构（5-10分钟）

**重组为口播**：
```
[0-30秒]  故事开场：选最有画面感的案例/场景
[30秒-3分] 论点1 + 信息高潮点 + 弹幕触发
[3-6分]   论点2 + 信息高潮点 + 弹幕互动
[6-9分]   论点3 + 反转/冷知识 + 深度展开
[9-10分]  金句+预告+三连
```

## 三、信息密度调整规则

### 源文有5个论点时

| 平台 | 保留论点数 | 筛选策略 |
|------|-----------|---------|
| 抖音 | 2-3个 | 选最反常识/最震撼的 |
| 视频号 | 1-2个 | 选最有阅历感的（30-50岁受众关心的事） |
| B站 | 3-4个 | 选最有故事性/可深挖的 |
| 小红书 | 1-2个 | 选最实操的（可收藏的） |

### 论据筛选规则
- **短视频**：每个论点只留1个最强论据（数字/案例），删掉其余
- **B站**：每个论点可展开2-3个论据，但必须有故事性
- **视频号**：论据要贴近生活场景（"前段时间我发现"）
- **小红书**：论据要可操作（步骤/清单）

## 四、语气切换矩阵

| 维度 | 抖音口播 | 视频号 | B站知识区 | 小红书视频 |
|------|---------|--------|----------|-----------|
| 人称 | 你/大家 | 咱们/你 | 你/大家 | 姐妹们/你 |
| 语气词 | 嘛/呗/啊 | 嘛/啊 | 嘛/呢/啊 | 啊/呀/啦 |
| 判断词 | 说白了/核心是 | 说白了/琢磨透了 | 关键在于/本质上 | 说真的/真心话 |
| 感叹频率 | 极高 | 低 | 中 | 高 |
| 反问句 | 常用 | 禁用 | 常用 | 少用 |
| 称呼读者 | 你 | 咱们 | 你 | 姐妹们 |
| 自称 | 我 | 我 | 我/UP主 | 我 |

## 五、金句提取与改写规则

### 金句提取
从长文中提取可传播金句，标准：
- 短（≤25字）
- 有对比/有画面感
- 能脱离上下文独立传播

### 金句改写（如果源文金句不够口语化）

| 长文金句 | 口播金句 | 改写规则 |
|---------|---------|---------|
| "内容创作的本质是价值传递" | "你写的不是内容，是价值" | 抽象→具体，名词替换 |
| "在信息过载时代，注意力是最稀缺的资源" | "别想着让人看完——先让他停下来" | 概念→行动 |
| "传统营销模式的失效源于信任机制的崩塌" | "老套路骗不了人了——信任比流量值钱" | 学术→口语+对比 |
| "数字化转型不是技术问题，是认知问题" | "数字化不是装个系统——是换脑子" | 技术术语→口语比喻 |

## 六、标题转化规则

同一个选题，不同平台的标题完全不同。

### 示例选题：AI不会取代你，但会用AI的人会

| 平台 | 标题 |
|------|------|
| 抖音 | 99%的人都搞错了！AI不会取代你，但这件事会 |
| 视频号 | 关于AI焦虑，有个事你一定得知道—— |
| B站 | AI到底会不会取代你？我调研了100个案例，答案出乎意料 |
| 小红书 | AI焦虑？3个真相让你瞬间清醒💡 |

### 标题公式映射

| 抖音公式 | 视频号变体 | B站变体 | 小红书变体 |
|---------|-----------|--------|-----------|
| 数字+震惊 | 关于XX有个事 | 我调研了X个XX | XX真相💡 |
| 反常识+悬念 | XX其实就一句话 | XX的真相是什么 | 反常识+感叹 |
| 身份+必看 | 做XX的注意了 | 作为XX我想说 | XX党必看 |
| 对比+站队 | A和B的区别就一点 | A vs B终极对比 | A vs B谁更XX |
