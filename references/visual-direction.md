# 视觉指令参考指南

## 一、镜头类型

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 近景 | 肩以上，面部表情清晰 | Hook开场、金句收尾、情绪高点 |
| 中景 | 半身，手势可见 | 主体段落、过渡衔接、方法讲解 |
| 远景 | 全身，背景可见 | 开场定位、场景切换、结尾定格 |
| 特写 | 手/道具/屏幕细节 | 数据展示、道具展示、操作演示 |
| 过肩镜头 | 从后方拍摄，屏幕在前 | 操作演示、界面展示 |

### 镜头切换节奏
- 抖音/小红书：每10-15秒切一次镜头
- 视频号：每20-30秒切一次镜头
- B站：每1-2分钟切一次镜头（弹幕密集处多切）

## 二、B-roll（补充画面素材）

### B-roll类型库

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 数据图表 | 可视化数据 | 引用数据、对比分析 |
| 操作画面 | 手机/电脑操作演示 | 教程类、工具推荐类 |
| 场景空镜 | 城市/办公/生活场景 | 背景交代、情绪烘托 |
| 动画插图 | 简笔画/概念图 | 抽象概念解释、流程展示 |
| 真实案例 | 企业/产品/人物素材 | 案例佐证、品牌提及 |
| 对比画面 | 前后对比/左右对比 | 方法效果、差距展示 |

### B-roll使用原则
1. 口播台词和B-roll内容**不同步**——口播说A画面放B，避免"念画面"
2. B-roll时长3-5秒，切入后口播继续说
3. 每个段落至少1个B-roll切换点
4. B站中视频B-roll占比30-40%，短视频占比15-20%

## 三、字幕系统

### 字幕层级

| 层级 | 位置 | 内容 | 字数 |
|------|------|------|------|
| 底部横条字幕 | 画面底部1/5 | 口播台词全文（短视频可选） | 全文 |
| 关键信息字幕 | 居中弹出 | 核心论点/数据/金句 | ≤15字 |
| 侧边标注 | 画面右侧 | 补充信息/引用来源 | ≤10字 |

### 字幕样式参考

| 样式 | 说明 | 适用场景 |
|------|------|---------|
| 底部横条 | 白字+黑底半透明条 | 常规口播，最通用 |
| 居中弹出 | 大字居中+动画弹出 | Hook/金句/核心观点 |
| 渐入渐出 | 字幕平滑淡入淡出 | 数据/方法/步骤 |
| 侧边标注 | 小字侧边+线条指引 | 来源标注/补充说明 |
| 打字机效果 | 逐字出现 | 悬念制造/揭示答案 |

### 字幕制作原则
- 关键信息必有字幕（观众不听也能看懂）
- 字幕文字≠口播台词（字幕是提炼，不是照搬）
- 金句字幕独立成行，加粗加大
- 数据字幕用数字+颜色强调

## 四、音效体系

| 音效 | 说明 | 适用时机 |
|------|------|---------|
| 鼓点 | 短促有力 | Hook开场、论点切换 |
| 倒计时音 | 滴滴滴 | 数据展示、紧迫感制造 |
| 升调 | 音调逐渐升高 | 情绪爬坡、制造期待 |
| 降调 | 音调突然降低 | 金句收束、结论落地 |
| 安静 | 2秒无音效 | 金句前留白、制造反差 |
| 轻快BGM | 节奏感强但不过激 | 方法讲解、实操演示 |
| 沉稳BGM | 低频+稳定 | 深度分析、趋势判断 |
| 弹幕音效 | 轻微互动声 | 弹幕触发点（B站专用） |

### 音效使用原则
- 短视频音效占比10-15%，B站音效占比5-10%
- 金句前必须有2秒安静留白
- 切换段落时用鼓点或音效过渡
- 不要全程同一BGM

## 五、道具与背景

### 常用道具清单

| 道具 | 说明 | 适用场景 |
|------|------|---------|
| 手机 | 展示操作/对比 | 教程类、工具类 |
| 笔记本 | 写要点/画流程 | 方法类、流程类 |
| 白板/黑板 | 写关键词/画图 | 概念讲解、逻辑梳理 |
| 产品实物 | 展示效果 | 产品推荐、评测类 |
| 书/杂志 | 引用出处 | 引用类、知识类 |

### 背景设置

| 背景 | 说明 | 适用场景 |
|------|------|---------|
| 书房/办公室 | 专业但不冷 | 知识类、职场类、方法论 |
| 简约白墙 | 干净聚焦 | 抖音口播最通用 |
| 生活场景 | 真实感强 | 生活经验类、痛点共鸣类 |
| 户外 | 自然放松 | 旅行/生活方式类 |

### 背景切换原则
- 不同段落可切换背景位置（书桌→沙发→白墙）
- B站中视频开场和结尾背景可不同
- 短视频全程同一背景（切换靠镜头和B-roll）
